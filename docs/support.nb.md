# Support: meld feil og foreslå idéer

Vi samler feil og funksjonsønsker offentlig på GitHub — der kan du også legge ved skjermbilder
direkte via dra og slipp.

<div class="grid cards" markdown>

- :material-bug: **Meld en feil**

    [Åpne nytt bug-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=bug_report.md){ .md-button .md-button--primary }

- :material-lightbulb-on: **Foreslå en funksjon**

    [Åpne nytt feature-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=feature_request.md){ .md-button }

</div>

Alle åpne og allerede løste temaer finner du i
[issue-oversikten](https://github.com/gcprogram/gcmystsolver-feedback/issues).

## Hva en god feilrapport bør inneholde

1. **Hva som skjedde** kontra **hva du forventet**
2. Den berørte cachen (GC-kode) eller skjermen, hvis relevant
3. Et **skjermbilde** (bare dra det inn i issue-feltet)
4. Din app-versjon (Setup → About the app)

En GitHub-konto er gratis og tar rundt 30 sekunder å opprette hvis du ikke allerede har en.
