# Support : signaler des bugs et proposer des idées

Nous collectons les bugs et les demandes de fonctionnalités publiquement sur GitHub — tu peux
aussi y joindre directement des captures d'écran par glisser-déposer.

<div class="grid cards" markdown>

- :material-bug: **Signaler un bug**

    [Ouvrir un nouveau bug-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=bug_report.md){ .md-button .md-button--primary }

- :material-lightbulb-on: **Proposer une fonctionnalité**

    [Ouvrir un nouveau feature-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=feature_request.md){ .md-button }

</div>

Tu trouveras tous les sujets ouverts et déjà résolus dans l'
[aperçu des issues](https://github.com/gcprogram/gcmystsolver-feedback/issues).

## Ce que contient un bon rapport de bug

1. **Ce qui s'est passé** vs. **ce à quoi tu t'attendais**
2. La cache concernée (code GC) ou l'écran, si pertinent
3. Une **capture d'écran** (glisse-la simplement dans le champ de l'issue)
4. Ta version de l'application (Setup → About the app)

Un compte GitHub est gratuit et se crée en environ 30 secondes si tu n'en as pas encore.
