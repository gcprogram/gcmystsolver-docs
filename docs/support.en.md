# Support: Report Bugs & Suggest Ideas

We collect bugs and feature requests publicly on GitHub — you can also attach screenshots there
directly via drag & drop.

<div class="grid cards" markdown>

- :material-bug: **Report a bug**

    [Open new bug issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=bug_report.md){ .md-button .md-button--primary }

- :material-lightbulb-on: **Suggest a feature**

    [Open new feature issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=feature_request.md){ .md-button }

</div>

You'll find all open and already resolved topics in the
[issue overview](https://github.com/gcprogram/gcmystsolver-feedback/issues).

## What a good bug report includes

1. **What happened** vs. **what you expected**
2. The affected cache (GC code) or screen, if relevant
3. A **screenshot** (just drag it into the issue field)
4. Your app version (Setup → About the app)

A GitHub account is free and takes about 30 seconds to create if you don't have one yet.
