# FAQ

**Do I absolutely need an AI API key?**
No. The automatic solvers work without AI. A key only extends what's additionally attempted
automatically.

**Does the app cost anything?**
No, GCMystSolver itself is free. If you use the optional AI connection, that incurs cost with the
respective AI provider (your own API key, you pay them directly — see
[AI Solving](funktionen/ki-solver.md) for a rough token estimate).

**Why is my multi-cache marked as "not automatically solvable" even though it contains a puzzle?**
The app recognizes hard evidence of a field puzzle (e.g. several stages in the listing or real
waypoints in the GPX file) and deliberately doesn't try to solve such caches automatically/via
AI — an on-site element can't be cracked from your armchair.

**My challenge shows red/yellow even though I actually satisfy it — what should I do?**
Check the displayed evidence list resp. the detected text/value on the detail page — this is
often due to a find that hasn't been imported yet, or an ambiguous free-text detection. If you
suspect a real bug in the detection, [please report it](support.md) — ideally with the cache's GC
code.

**I have an idea for a new solver or challenge type — where do I put it?**
As a feature suggestion via [Support](support.md).
