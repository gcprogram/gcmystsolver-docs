# Soporte: reportar errores y proponer ideas

Recopilamos errores y solicitudes de funciones públicamente en GitHub — allí también puedes
adjuntar capturas de pantalla directamente arrastrándolas.

<div class="grid cards" markdown>

- :material-bug: **Reportar un error**

    [Abrir nuevo issue de error](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=bug_report.md){ .md-button .md-button--primary }

- :material-lightbulb-on: **Proponer una función**

    [Abrir nuevo issue de función](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=feature_request.md){ .md-button }

</div>

Encontrarás todos los temas abiertos y ya resueltos en la
[vista general de issues](https://github.com/gcprogram/gcmystsolver-feedback/issues).

## Qué incluye un buen reporte de error

1. **Qué ocurrió** frente a **qué esperabas**
2. El caché afectado (código GC) o la pantalla, si es relevante
3. Una **captura de pantalla** (simplemente arrástrala al campo del issue)
4. Tu versión de la app (Setup → About the app)

Una cuenta de GitHub es gratis y se crea en unos 30 segundos si aún no tienes una.
