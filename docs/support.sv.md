# Support: rapportera buggar och föreslå idéer

Vi samlar buggar och funktionsönskemål öppet på GitHub — där kan du också bifoga skärmdumpar
direkt via drag & drop.

<div class="grid cards" markdown>

- :material-bug: **Rapportera en bugg**

    [Öppna nytt bug-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=bug_report.md){ .md-button .md-button--primary }

- :material-lightbulb-on: **Föreslå en funktion**

    [Öppna nytt feature-issue](https://github.com/gcprogram/gcmystsolver-feedback/issues/new?template=feature_request.md){ .md-button }

</div>

Alla öppna och redan lösta ämnen hittar du i
[issue-översikten](https://github.com/gcprogram/gcmystsolver-feedback/issues).

## Vad en bra buggrapport innehåller

1. **Vad som hände** kontra **vad du förväntade dig**
2. Den berörda cachen (GC-kod) eller skärmen, om relevant
3. En **skärmdump** (dra den bara in i issue-fältet)
4. Din app-version (Setup → About the app)

Ett GitHub-konto är gratis och tar cirka 30 sekunder att skapa om du inte redan har ett.
