# Preguntas frecuentes

**¿Necesito obligatoriamente una clave API de IA?**
No. Los solucionadores automáticos funcionan sin IA. Una clave solo amplía lo que se intenta
adicionalmente de forma automática.

**¿Cuesta algo la app?**
No, GCMystSolver en sí es gratuita. Si usas la conexión IA opcional, eso genera costes con el
proveedor de IA correspondiente (tu propia clave API, pagas directamente allí — ver
[Resolución con IA](funktionen/ki-solver.md) para una estimación aproximada de tokens).

**¿Por qué se marca mi multi-caché como "no resoluble automáticamente" aunque contenga un
enigma?**
La app reconoce indicios sólidos de un enigma de campo (p. ej. varias etapas en el listado o
waypoints reales en el archivo GPX) y evita deliberadamente intentar resolver esos caches de
forma automática/por IA — un elemento in situ no se puede resolver desde el sofá.

**Mi challenge se muestra en rojo/amarillo aunque en realidad lo cumplo — ¿qué hago?**
Comprueba la lista de evidencias mostrada o el texto/valor detectado en la página de detalle — a
menudo se debe a un hallazgo aún no importado o a una detección de texto libre ambigua. Si
sospechas un error real en la detección, [repórtalo](support.md) — idealmente con el código GC del
caché.

**Tengo una idea para un nuevo solucionador o tipo de challenge — ¿dónde la propongo?**
Como sugerencia de función a través de [Soporte](support.md).
