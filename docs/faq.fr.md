# FAQ

**Ai-je absolument besoin d'une clé API IA ?**
Non. Les solveurs automatiques fonctionnent sans IA. Une clé ne fait qu'étendre ce qui est tenté
automatiquement en plus.

**L'application coûte-t-elle quelque chose ?**
Non, GCMystSolver elle-même est gratuite. Si tu utilises la connexion IA optionnelle, cela
entraîne des coûts chez le fournisseur d'IA concerné (ta propre clé API, tu payes directement
là-bas — voir [Résolution par IA](funktionen/ki-solver.md) pour une estimation approximative en
tokens).

**Pourquoi ma cache multi est-elle marquée « non résoluble automatiquement » alors qu'elle
contient une énigme ?**
L'application détecte des indices solides d'une énigme de terrain (par ex. plusieurs étapes dans
le listing ou de vrais waypoints dans le fichier GPX) et évite délibérément de tenter de résoudre
de telles caches automatiquement/par IA — un élément sur place ne peut pas être percé depuis ton
canapé.

**Mon challenge s'affiche en rouge/jaune alors que je le remplis en réalité — que faire ?**
Vérifie la liste de preuves affichée ou le texte/valeur détecté sur la page de détail — c'est
souvent dû à une trouvaille pas encore importée ou à une détection ambiguë dans le texte libre. Si
tu soupçonnes un vrai bug de détection, [signale-le](support.md) — idéalement avec le code GC de
la cache.

**J'ai une idée de nouveau solveur ou de nouveau type de challenge — où la proposer ?**
Comme suggestion de fonctionnalité via [Support](support.md).
