# AI-Chat pro Cache

Für den Fall, dass eine automatisch gefundene Lösung falsch ist oder gar keine gefunden wurde,
kannst du auf der Detailseite eines Caches einen **Vollbild-Chat** mit der KI öffnen — speziell zu
genau diesem einen Cache.

## Was der Chat weiß

Der Chat startet mit dem vollständigen Kontext des Caches: Listing-Text, Hinweis (Hint) und die
bisherige (ggf. falsche) Lösung. Du kannst zusätzlich eigene Fotos mitschicken, z. B. von einem
Hinweisschild oder einem Rätselelement, das nicht im Listing-Text steht.

## Solver auf Zuruf

Mitten im Gespräch kann die KI selbstständig einen der klassischen Solver aufrufen (what3words,
Vigenère, ROT-N, Krypto-Dekoder, Enigma, Reverse-Wherigo) — z. B. um einen im Chat besprochenen
Zwischentext direkt zu entschlüsseln. Das Ergebnis erscheint als eigener, klar gekennzeichneter
Chat-Eintrag und die KI bezieht es automatisch in ihre nächste Antwort ein. Pro Nachricht sind das
maximal drei automatische KI-Antwortrunden, damit sich das Gespräch nicht in einer Endlosschleife
verliert.

## Lösung übernehmen

Kommt ihr im Chat auf eine bessere Lösung, übernimmst du sie über den Button **"Take over as
solution"** direkt in die Cache-Datenbank — ohne die Lösung manuell woanders eintragen zu müssen.
